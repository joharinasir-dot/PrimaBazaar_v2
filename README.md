## 📌 Pengenalan / Overview

**PrimaBazaar** ialah aplikasi web pasaran komuniti dalaman (*internal peer-to-peer marketplace*) yang dibina khusus untuk kakitangan syarikat media terbesar Malaysia, **Media Prima Berhad**. Platform ini memudahkan transaksi jual-beli sarapan pagi segar buatan staf, pakaian rasmi krew penyiaran, gajet pejabat, dan peralatan rumah sesama rakan sekerja secara telus, selamat, dan bebas komisen luar.

Aplikasi ini disepadukan dengan sistem pengesahan identiti tunggal syarikat (**Microsoft Azure Active Directory SSO**) serta mematuhi piawaian integriti **Tatakelakuan & Etika Perniagaan (COBE)** Kumpulan Media Prima.

## ✨ Ciri-Ciri Utama / Key Features

### 1. 🛒 Pasar Utama & Jualan Kilat (*Marketplace Feed & Flash Sale*)
- **Pengepala Korporat & Penukar Hab Serahan:** Pilihan lokasi fleksibel antara *Sri Pentas (Bandar Utama)*, *Balai Berita NSTP (Bangsar)*, *Studio Glenmarie (Shah Alam)*, dan *REV Media Hub (Aras 3)*.
- **Kempen Bazar Pagi:** Sorotan harian barangan kru TV3, NSTP & REV Media dengan statistik tawaran baharu.
- **8 Kategori Pantas:** Pintasan satu klik untuk *Sarapan Kafe*, *Jualan Kilat MP*, *COD Sri Pentas*, *Balai Berita NSTP*, *Pakaian Kru*, *Gajet IT Pejabat*, *Penjual Top Staf*, dan *Jaminan COBE*.
- **Jualan Kilat Media Prima:** Pemasa undur masa (*countdown timer*) masa nyata dengan bar kemajuan stok barangan (*cth: Nasi Lemak Sambal Sotong Kak Ani, Brownies Fudgy Sea Salt, Logitech MX Master 3S*).
- **Cadangan Harian & Tapisan Dinamik:** Pengisihan pintar mengikut *Paling Popular* atau *Harga Rendah*.

### 2. 🍲 Halaman Butiran Barangan (*Product Detail Page*)
- **Galeri Foto Resolusi Tinggi:** Label waktu masakan segar pagi (5:30 PG), ID iklan rasmi (`#MPB-FD-2025-0814`), dan indikator stok baki.
- **Metrik Prestasi:** Kadar kepuasan (4.9/5.0), Waktu ambilan (8:00 – 9:30 PG), Status suhu (Masih Suam), dan Had penyediaan (30 pek).
- **Kisah Resipi & Senarai Kandungan:** Perincian warisan Pantai Timur resipi Kak Ani dan semakan 6 bahan bungkusan lengkap daun pisang.
- **Pilihan Tambahan (*Add-Ons*) Dinamik:** Pilihan interaktif *Ekstra Telur Rebus* (+RM1.00) dan *Sambal Sotong Asing* (+RM1.50) yang mengemas kini perkiraan harga serta-merta.
- **Pelan Tapak Kafeteria Interaktif:** Rajah pelan lantai Aras Bawah Kafeteria Sri Pentas yang menonjolkan lokasi *Meja Serahan Kak Ani* di sebelah Kaunter Minuman & Kaunter Kopi Pak Ali.
- **Modul Pembelian Lekat (*Sticky Purchase Module*):** Pelaras kuantiti, ruangan nota khas pesanan, butang bayar DuitNow QR, dan pautan terus ke sembang dalaman.

### 3. 💬 Sistem Pesanan & Sembang Bersepadu (*Orders & Chat*)
- **Dwi-Panel Responsif:** Senarai perbualan dengan tab *Semua*, *Belian Saya*, dan *Jualan Saya*, serta paparan skrin penuh di peranti mudah alih.
- **Sepanduk Peringatan Serahan Pagi:** Makluman waktu pengambilan barangan di kafeteria (08:30 – 09:30 PG).
- **Slip Rasmi Pindahan DuitNow:** Penjanaan resit transaksi Maybank2u/DuitNow lengkap dengan nombor rujukan rasmi, jumlah bayaran, dan pautan muat turun PDF.
- **Kad Status Pesanan Langsung:** Status proses ambilan sendiri dengan butang tindakan pantas *Navigasi Kafeteria* dan *Beri Penilaian*.
- **Panggilan Sambungan Pejabat (*Ext Call*):** Panggilan pantas ke sambungan telefon dalaman penjual (*cth: Ext 8421*).
- **Cip Balas Pantas:** Respons segera seperti *"Saya dah sampai di kaunter!"* atau *"Minta rakan sepasukan tolong ambilkan"*.

### 4. 📝 Terbitkan Iklan (*Publish Listing / Sell*)
- **Status Penjual Disahkan:** Paparan profil rasmi Nurul Aini (Wartawan Penyiaran Kanan, MP-88421) dengan pengesahan SSO Azure AD.
- **5 Langkah Teratur:**
  1. *Muat Naik Gambar:* Penandaan foto utama (*Cover*), pratonton gambar, dan fungsi padam.
  2. *Maklumat & Kategori:* Tajuk dengan had 80 aksara, pemilihan kategori (Makanan, Pakaian, Gajet, Pejabat), penarafan kondisi (10/10, 9/10, 7/10), dan keterangan terperinci.
  3. *Harga & Kaedah Bayaran:* Penetapan harga, pilihan rundingan harga (*nego*), sokongan DuitNow QR dan COD Tunai.
  4. *Titik Serahan Fizikal:* Pemilihan hab bangunan, lokasi bilik/pantri spesifik, waktu serahan, dan pilihan titipan di Concierge Lobi.
  5. *Pengesahan Integriti (COBE):* Perakuan wajib pematuhan Tatakelakuan Pekerja (Rujukan: HR-COBE-2024/REV-03).

### 5. ⭐ Profil Penjual & Penilaian Komuniti (*Seller Profile & Reviews*)
- **Profil Kak Ani (Hjh Rohani):** Penyelia Produksi TV3 dengan rekod perkhidmatan 14 tahun dan pematuhan COBE 100%.
- **Skor & Pecahan Penilaian:** 4.9/5.0 daripada 84 ulasan rakan sekerja berserta graf pecahan bintang (5★, 4★, 3★).
- **Tag Pujian Komuniti:** Kekerapan pujian seperti *Sambal Padu & Sedap*, *Serahan Tepat Masa*, *Mesra Rakan Sekerja*, dan *Bungkusan Bersih*.
- **Stok Langsung di Kafe:** Widget baki stok masa nyata dengan tindakan tempah segera.
- **Modul Pop-up Beri Penilaian:** Penarafan 1–5 bintang interaktif, pemilihan tag pujian, ruangan komen ulasan, muat naik foto, dan penerbitan langsung ke suapan ulasan.

### 6. 📱 Responsif Sepenuhnya (*Fully Responsive Mobile UX*)
- Bar navigasi bawah khas telefon pintar (*Pasar*, *Carian*, butang timbul *+ Iklan*, *Pesanan*, *Profil*).
- Susun atur optimum pada skrin mudah alih, tablet, serta paparan skrin lebar 1440px desktop.

## 🚀 Panduan Pemasangan & Pembangunan / Local Setup

### Prasyarat
- **Node.js** versi 18.x atau ke atas
- Pengurus pakej **npm** atau **yarn**

### Langkah Pemasangan

1. **Klon Repositori:**
   ```bash
   git clone https://github.com/your-username/primabazaar-mediaprima.git
   cd primabazaar-mediaprima
   ```

2. **Pasang Dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Pelayan Pembangunan (*Dev Server*):**
   ```bash
   npm run dev
   ```
   Buka pelayar web di `http://localhost:3000` (atau port yang dipaparkan di terminal).

4. **Semakan Kod & Validasi TypeScript (*Linting*):**
   ```bash
   npm run lint
   ```

5. **Bina untuk Pengeluaran (*Production Build*):**
   ```bash
   npm run build
   ```

Semua urus niaga dalam **PrimaBazaar** tertakluk di bawah **Tatakelakuan & Etika Perniagaan Media Prima Berhad (COBE)**:
- **Pengesahan Azure SSO:** Hanya kakitangan sah berdaftar boleh membuat transaksi.
